# HelpHub Volunteer Coordination Platform

HelpHub is a volunteer coordination platform that connects volunteers with organizations and community opportunities.

## Live Demo

🌐 **Frontend:** https://helphub-frontend.vercel.app

🚀 **Backend API:** https://helphub-mc2q.onrender.com

## Project Features

- Firebase Authentication
- Volunteer and organization accounts
- Volunteer opportunity management
- Volunteer signups
- Volunteer hours tracking
- Certificate generation
- Organization logo uploads
- Event photo uploads
- Supabase file storage
- MongoDB database
- REST API using Node.js and Express

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Firebase Authentication
- Firebase Admin SDK
- Supabase Storage
- PDFKit
- Swagger API Documentation
